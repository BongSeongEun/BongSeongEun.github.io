4. 홈 화면 구성 및 관리 ​

홈 화면은 방문객이 축제 및 행사 안내 페이지에서 주요 정보와 서비스를 확인할 수 있는 공간입니다.

프로젝트 운영자는 CMS를 통해 메인 배너, 하이라이트, 바로가기, 하단 푸터 등을 설정하여 행사 특성에 맞는 홈 화면을 구성할 수 있습니다.

각 구성 요소는 개별 관리 메뉴에서 등록하거나 수정할 수 있으며, 변경한 내용은 저장 후 방문객용 안내 페이지에서 확인할 수 있습니다.

4.1. 홈 화면 관리 메뉴 ​

홈 화면의 각 구성 요소는 프로젝트 관리 화면에서 개별 메뉴를 통해 관리합니다.

메뉴설명
메인 배너홈 화면에 표시할 대표 이미지 및 연결 링크 관리
하이라이트방문객에게 강조할 주요 행사 일정 및 콘텐츠 설정
바로가기주요 서비스나 페이지로 이동하는 바로가기 메뉴 관리
하단 푸터홈 화면 하단에 표시할 이미지 및 배경색 설정

참고

홈 화면에 표시되는 구성 요소는 프로젝트 설정에 따라 달라질 수 있습니다.

각 메뉴에서 콘텐츠를 등록한 후 방문객용 안내 페이지에서 정상적으로 표시되는지 확인해 주세요.

4.2. 메인 배너 관리 ​

메인 배너는 홈 화면에서 행사의 대표 이미지나 주요 안내 사항을 보여주는 영역입니다.

여러 개의 배너를 등록할 수 있으며, 배너별 이미지, 연결 링크 및 표시 순서를 설정할 수 있습니다.

① 메인 배너 관리 화면 이동 ​

  1. 프로젝트 관리 화면에서 메인 배너 메뉴를 선택합니다.
  2. 현재 등록된 배너 목록을 확인합니다.
  3. 새로운 배너를 추가하거나 기존 배너를 수정할 수 있습니다.

② 메인 배너 등록 ​

등록 방법

  1. 배너 이미지 영역에서 이미지 파일을 선택합니다.
  2. 등록할 이미지가 올바른지 확인합니다.
  3. 추가 버튼을 클릭합니다.
  4. 추가된 배너에 필요한 연결 링크를 설정합니다.
  5. 화면 상단의 저장 버튼을 클릭합니다.

권장 이미지 규격

항목권장 사양
가로 크기1080px
세로 크기610px
최대 파일 크기10MB

이미지는 가로형 이미지 사용을 권장합니다.

③ 배너 연결 링크 설정 ​

배너를 클릭했을 때 이동할 페이지를 설정할 수 있습니다.

링크 유형설명
없음배너 클릭 시 별도의 페이지로 이동하지 않음
내부 링크안내 페이지 내 다른 화면으로 이동
외부 링크지정한 외부 웹사이트로 이동

설정 방법

  1. 등록된 배너의 링크 유형 항목을 확인합니다.
  2. 원하는 링크 유형을 선택합니다.
  3. 내부 링크의 경우 이동할 내부 경로를 지정합니다.
  4. 외부 링크의 경우 이동할 URL을 입력합니다.
  5. 변경 내용을 저장합니다.

참고

외부 링크를 설정할 경우 https://를 포함한 전체 주소를 입력하는 것을 권장합니다.

④ 배너 순서 변경 ​

등록된 배너는 드래그하여 표시 순서를 변경할 수 있습니다.

  1. 순서를 변경할 배너를 선택합니다.
  2. 배너의 순서 변경 영역을 드래그합니다.
  3. 원하는 위치로 이동합니다.
  4. 변경된 순서를 확인한 후 저장합니다.

⑤ 배너 수정 및 삭제 ​

기존 배너의 이미지를 변경하거나 불필요한 배너를 삭제할 수 있습니다.

이미지 변경

  1. 변경할 배너의 이미지 변경 버튼을 클릭합니다.
  2. 새로운 이미지 파일을 선택합니다.
  3. 변경 내용을 저장합니다.

배너 삭제

  1. 삭제할 배너의 삭제 버튼을 클릭합니다.
  2. 삭제할 배너가 올바른지 확인합니다.
  3. 변경 내용을 저장합니다.

4.3. 하이라이트 관리 ​

하이라이트는 행사 일정 콘텐츠 중 조회수가 높은 콘텐츠를 홈 화면에 우선적으로 노출하는 기능입니다.

콘텐츠별 실제 조회수와 관리자가 설정한 가중치를 합산하여 노출 순위를 결정합니다.

이를 통해 방문객의 관심도가 높은 일정을 자동으로 노출하거나, 운영자가 특별히 홍보하고 싶은 일정을 우선적으로 노출할 수 있습니다.

① 하이라이트 관리 화면 이동 ​

  1. 프로젝트 관리 화면에서 하이라이트 메뉴를 선택합니다.
  2. 등록된 행사 일정 목록과 현재 설정된 가중치를 확인합니다.
  3. 필요에 따라 표시 개수와 콘텐츠별 가중치를 설정합니다.

② 하이라이트 표시 개수 설정 ​

홈 화면에 표시할 하이라이트 콘텐츠의 개수를 설정합니다.

설정한 개수만큼 조회수 순위가 높은 콘텐츠가 홈 화면에 노출됩니다.

③ 콘텐츠별 가중치 설정 ​

가중치는 특정 콘텐츠를 홈 화면에 우선적으로 노출하기 위해 부여하는 추가 조회수입니다.

하이라이트 노출 기준

노출 기준 조회수 = 실제 조회수 + 설정 가중치

예를 들어 다음과 같이 설정한 경우:

콘텐츠실제 조회수가중치노출 기준 조회수
개막식 공연3001,0001,300
푸드트럭 행사8500850
버스킹 공연500200700
체험 프로그램6000600

하이라이트 표시 개수를 3개로 설정했다면 다음 순서로 노출됩니다.

  1. 개막식 공연 (1,300)
  2. 푸드트럭 행사 (850)
  3. 버스킹 공연 (700)

실제 조회수가 낮더라도 높은 가중치를 부여하면 하이라이트에 우선적으로 노출할 수 있습니다.

④ 하이라이트 활용 예시 ​

하이라이트 기능은 다음과 같은 상황에서 활용할 수 있습니다.

  • 주요 공연 홍보: 개막식이나 특별 공연에 높은 가중치를 부여하여 우선 노출
  • 신규 프로그램 홍보: 조회수가 적은 신규 콘텐츠에 가중치를 부여하여 노출 기회 확대
  • 인기 콘텐츠 안내: 별도의 가중치 없이 실제 조회수가 높은 콘텐츠를 우선 노출

행사의 운영 목적에 맞게 가중치를 조정하면 방문객의 관심도와 운영자의 홍보 우선순위를 함께 반영할 수 있습니다.

4.4. 바로가기 관리 ​

바로가기는 방문객이 주요 서비스나 외부 페이지에 빠르게 접근할 수 있도록 제공하는 기능입니다.

바로가기에는 이미지, 이름 및 연결 링크를 설정할 수 있습니다.

① 바로가기 관리 화면 이동 ​

  1. 프로젝트 관리 화면에서 바로가기 메뉴를 선택합니다.
  2. 현재 등록된 바로가기 목록을 확인합니다.
  3. 필요한 경우 새로운 바로가기 항목을 추가합니다.

② 바로가기 기본 설정 ​

바로가기 영역의 홈 화면 표시 여부와 타이틀을 설정할 수 있습니다.

항목설명
홈 화면 표시홈 화면에 바로가기 영역을 표시할지 설정
타이틀바로가기 영역에 표시되는 제목

설정 방법

  1. 홈 화면 표시 항목을 활성화합니다.
  2. 타이틀 항목에 표시할 제목을 입력합니다.
  3. 변경 내용을 저장합니다.

③ 바로가기 항목 등록 ​

바로가기 항목별로 이미지, 이름 및 이동할 링크를 설정합니다.

항목설명
이미지바로가기 메뉴에 표시할 이미지
이름바로가기 메뉴의 이름
링크 유형내부 링크 또는 외부 링크 선택
내부 경로안내 페이지 내 이동할 경로
URL외부 웹사이트의 접속 주소

등록 방법

  1. 바로가기 추가 영역으로 이동합니다.
  2. 사용할 이미지를 등록합니다.
  3. 바로가기 이름을 입력합니다.
  4. 링크 유형을 선택합니다.
  5. 내부 경로 또는 외부 URL을 설정합니다.
  6. 추가 버튼을 클릭합니다.
  7. 등록된 항목을 확인한 후 화면 상단의 저장 버튼을 클릭합니다.

권장 이미지 규격

항목권장 사양
가로 크기240px
세로 크기240px
최대 파일 크기2MB

④ 바로가기 수정 및 삭제 ​

바로가기 수정

  1. 수정할 바로가기 항목의 수정 버튼을 클릭합니다.
  2. 이미지, 이름 또는 링크를 변경합니다.
  3. 수정 버튼을 클릭합니다.
  4. 변경된 내용을 저장합니다.

바로가기 삭제

  1. 삭제할 항목의 삭제 버튼을 클릭합니다.
  2. 삭제 확인 창이 표시되면 내용을 확인합니다.
  3. 삭제를 진행합니다.
  4. 변경 내용을 저장합니다.

⑤ 바로가기 활용 예시 ​

바로가기 이름활용 목적
행사 일정공연 및 프로그램 일정으로 이동
행사장 지도투어맵 화면으로 이동
스탬프 투어스탬프 투어 참여 화면으로 이동
공식 홈페이지행사 공식 웹사이트로 이동
교통 안내외부 교통 정보 페이지로 이동

참고

내부 링크를 이용하면 안내 페이지 내 주요 기능으로 이동할 수 있습니다.

외부 링크는 별도의 웹사이트로 이동하는 경우에 사용합니다.

4.5. 하단 푸터 관리 ​

하단 푸터는 홈 화면의 가장 아래쪽에 표시되는 이미지 영역입니다.

푸터 이미지와 배경색을 설정하여 홈 화면 하단의 디자인을 구성할 수 있습니다.

① 하단 푸터 설정 화면 이동 ​

  1. 프로젝트 관리 화면에서 하단 푸터 메뉴를 선택합니다.
  2. 현재 설정된 이미지와 배경색을 확인합니다.

② 홈 화면 표시 설정 ​

홈 화면 표시 항목을 이용하여 푸터 영역의 표시 여부를 설정할 수 있습니다.

  • 활성화: 홈 화면에 푸터 영역 표시
  • 비활성화: 홈 화면에서 푸터 영역 숨김

③ 푸터 이미지 등록 ​

  1. 이미지 추가 영역에서 사용할 이미지 파일을 선택합니다.
  2. 등록된 이미지를 확인합니다.
  3. 필요한 경우 이미지 변경을 통해 다른 이미지로 교체합니다.
  4. 설정을 저장합니다.

푸터 이미지는 홈 화면 하단에서 이미지 비율을 유지하면서 가로 너비에 맞춰 표시됩니다.

④ 배경색 설정 ​

푸터 이미지의 배경 또는 하단 여백 영역에 적용할 색상을 설정합니다.

설정 방법

  1. 배경색 항목으로 이동합니다.
  2. 원하는 색상을 선택합니다.
  3. 미리보기에서 적용된 모습을 확인합니다.
  4. 화면 상단의 저장 버튼을 클릭합니다.

배경색은 PNG 이미지의 배경 또는 하단 여백 영역에 사용됩니다.

4.6. 홈 화면 구성 확인 ​

모든 홈 화면 콘텐츠의 설정을 완료한 후에는 방문객용 안내 페이지에서 실제 표시 상태를 확인합니다.

① 확인 방법 ​

  1. 홈 화면에 사용할 콘텐츠의 등록 및 저장을 완료합니다.
  2. 방문객용 안내 페이지에 접속합니다.
  3. 홈 화면에 등록한 구성 요소가 표시되는지 확인합니다.
  4. 배너 및 바로가기의 연결 링크가 정상적으로 동작하는지 확인합니다.
  5. 모바일 화면에서 이미지와 텍스트가 잘리지 않는지 확인합니다.

② 최종 점검 항목 ​

  • 메인 배너 이미지가 정상적으로 표시되는지 확인
  • 배너의 표시 순서가 올바른지 확인
  • 배너 클릭 시 지정한 페이지로 이동하는지 확인
  • 하이라이트에 원하는 일정이 표시되는지 확인
  • 바로가기 이름과 이미지가 정상적으로 표시되는지 확인
  • 바로가기 링크가 올바르게 연결되는지 확인
  • 하단 푸터 이미지 및 배경색이 정상적으로 적용되는지 확인
  • 모바일 화면에서 전체 구성이 자연스럽게 표시되는지 확인
