9. 안내 페이지 공개 및 운영 ​

프로젝트의 기본 설정과 콘텐츠 등록이 완료되면 방문객에게 안내 페이지를 공개하고 운영할 수 있습니다.

프로젝트 운영자는 CMS에서 프로젝트 상태를 관리하고, 행사 운영 중 콘텐츠와 공지사항을 수정하여 방문객에게 최신 정보를 제공할 수 있습니다.

본 장에서는 안내 페이지 공개 전 점검, 프로젝트 상태 관리, 안내 페이지 접속 및 행사 운영 중 콘텐츠 관리 방법을 안내합니다.

9.1. 안내 페이지 공개 전 확인사항 ​

안내 페이지를 공개하기 전에는 프로젝트의 기본 설정과 주요 콘텐츠가 정상적으로 등록되어 있는지 확인해야 합니다.

① 프로젝트 기본 설정 확인 ​

프로젝트 설정 메뉴에서 다음 항목을 확인합니다.

확인 항목확인 내용
프로젝트 기본 정보행사명, 행사 기간 및 담당자 정보
브랜딩로고, 대표 색상, 강조 색상 및 글꼴
다국어기본 언어 및 지원 언어
서비스 모듈사용할 기능의 활성화 상태
하단 내비게이션메뉴 구성, 순서 및 최초 진입 화면

② 콘텐츠 등록 상태 확인 ​

다음 항목 중 프로젝트에서 사용하는 기능의 콘텐츠가 준비되었는지 확인합니다.

  • 메인 배너, 하이라이트, 바로가기 및 하단 푸터
  • 상세 콘텐츠 및 행사 일정
  • 투어맵 기본 설정 및 지도 객체
  • 스탬프 투어 코스 및 수집 지점
  • AI 챗봇, 설문조사, 오디오·비디오 가이드
  • 공지사항

참고

모든 서비스 기능을 반드시 사용할 필요는 없습니다. 프로젝트에서 활성화한 기능을 중심으로 점검해 주세요.

9.2. 프로젝트 상태 관리 ​

프로젝트 상태는 방문객에게 안내 페이지를 제공할지 결정하는 설정입니다.

프로젝트 운영자는 행사 준비, 운영 및 종료 상황에 따라 프로젝트 상태를 변경할 수 있습니다.

① 프로젝트 상태 안내 ​

상태설명방문객 화면
준비중프로젝트 준비 단계준비중 안내 페이지 표시
활성화안내 페이지 운영 단계정상 안내 페이지 표시
비활성화프로젝트 운영 중단 또는 종료안내 페이지 미표시

준비중

프로젝트의 콘텐츠를 등록하거나 서비스를 구성하는 단계에서 사용합니다.

방문객이 안내 페이지 주소로 접속하면 일반 안내 페이지 대신 준비중 안내 화면이 표시됩니다.

활성화

행사 안내 페이지의 구성이 완료되어 방문객에게 서비스를 제공할 때 사용합니다.

방문객은 홈, 투어맵, 일정 등 프로젝트에 설정된 기능을 정상적으로 이용할 수 있습니다.

비활성화

프로젝트 운영을 중단하거나 종료할 때 사용합니다.

방문객이 안내 페이지 주소로 접속하더라도 행사 안내 페이지가 제공되지 않습니다.

② 프로젝트 상태 변경 방법 ​

  1. CMS에서 관리할 프로젝트를 선택합니다.
  2. 프로젝트 설정 > 기본 정보 메뉴로 이동합니다.
  3. 상태 항목에서 원하는 상태를 선택합니다.
  4. 저장 버튼을 클릭합니다.
  5. 변경된 상태가 정상적으로 적용되었는지 확인합니다.

③ 프로젝트 상태별 화면 확인 ​

프로젝트 상태를 변경한 후에는 방문객용 안내 페이지에 접속하여 실제 표시 상태를 확인합니다.

주의사항

프로젝트를 비활성화하면 방문객에게 안내 페이지가 제공되지 않습니다.

행사 운영 중 실수로 비활성화하지 않도록 주의해 주세요. 행사 종료 후에도 방문객에게 정보를 제공해야 하는 경우에는 공개 유지 여부를 검토한 후 상태를 변경해 주세요.

④ 프로젝트 상태 활용 예시 ​

운영 단계권장 상태
프로젝트 최초 설정 및 콘텐츠 등록준비중
행사 안내 페이지 공개활성화
행사 진행 중활성화
행사 종료 후 안내 페이지 유지활성화
안내 페이지 서비스 종료비활성화

참고

프로젝트가 준비중 또는 비활성화 상태여도 관리자 권한이 있는 사용자는 CMS에서 프로젝트의 콘텐츠와 설정을 관리할 수 있습니다.

9.3. 안내 페이지 접속 및 공유 ​

프로젝트가 활성화되면 해당 프로젝트의 URL을 이용하여 방문객용 안내 페이지에 접속할 수 있습니다.

① 안내 페이지 URL 확인 ​

  1. CMS의 프로젝트 관리 화면으로 이동합니다.
  2. 공개한 프로젝트를 찾습니다.
  3. 상태가 활성화인지 확인합니다.
  4. 프로젝트 목록의 URL 항목에 있는 이동 버튼을 클릭합니다.
  5. 새 브라우저 탭에서 방문객용 안내 페이지가 열리는지 확인합니다.

② 안내 페이지 주소 ​

프로젝트의 안내 페이지 주소는 프로젝트별 URL Slug를 기준으로 구성됩니다.

주소 형식

https://{프로젝트 슬러그}.infodio.kr

예를 들어 슬러그가 sample-festival이면 안내 페이지 주소는 다음과 같습니다.

https://sample-festival.infodio.kr

※ 위 주소는 형식을 설명하기 위한 예시입니다.

③ 방문객에게 안내 페이지 공유 ​

확인한 안내 페이지 URL은 행사 홍보물 등에서 공유할 수 있습니다.

활용 예시

  • 행사 공식 홈페이지
  • SNS 및 온라인 홍보 게시물
  • 행사장 안내 배너
  • 리플릿 및 인쇄 홍보물
  • QR 코드 안내판

URL을 공유하기 전에 모바일에서 정상적으로 접속되는지 확인해 주세요.

9.4. 방문객용 안내 페이지 최종 점검 ​

안내 페이지를 활성화한 후에는 실제 방문객이 사용하는 환경에서 주요 기능을 점검합니다.

① 홈 화면 확인 ​

  1. 안내 페이지에 접속합니다.
  2. 메인 배너와 주요 콘텐츠가 정상적으로 표시되는지 확인합니다.
  3. 바로가기와 하단 내비게이션 메뉴를 선택합니다.
  4. 각 메뉴가 올바른 페이지로 이동하는지 확인합니다.

② 행사 콘텐츠 확인 ​

  • 상세 콘텐츠의 제목과 본문 확인
  • 이미지 및 영상 표시 확인
  • 행사 일정과 운영 시간 확인
  • 카테고리 및 배지 확인
  • 공지사항 내용 확인

③ 지도 및 참여형 서비스 확인 ​

  • 투어맵의 초기 위치와 지도 객체 표시 확인
  • 마커 선택 및 바텀시트 동작 확인
  • 스탬프 투어 코스와 수집 지점 확인
  • 설문조사 및 부가 서비스 동작 확인

④ 모바일 환경 점검 ​

방문객은 주로 모바일 기기를 이용하므로 모바일 환경에서의 확인이 중요합니다.

특히 다음 내용을 점검합니다.

  • 화면 너비에 맞게 콘텐츠가 표시되는지
  • 이미지와 텍스트가 잘리지 않는지
  • 버튼과 메뉴가 정상적으로 동작하는지
  • 하단 내비게이션이 올바르게 표시되는지
  • 언어 변경 시 콘텐츠가 정상적으로 제공되는지

9.5. 운영 중 콘텐츠 수정 ​

행사 운영 중 일정이나 장소 정보 등이 변경되면 CMS에서 해당 내용을 수정할 수 있습니다.

① 콘텐츠 수정 방법 ​

  1. CMS에 로그인합니다.
  2. 수정할 프로젝트의 관리 화면으로 이동합니다.
  3. 변경할 콘텐츠의 관리 메뉴를 선택합니다.
  4. 기존 내용을 수정합니다.
  5. 저장 버튼을 클릭합니다.
  6. 방문객용 안내 페이지에서 변경된 내용을 확인합니다.

② 운영 중 주요 수정 항목 ​

수정 항목활용 상황
행사 일정공연 시간 변경, 프로그램 취소
상세 콘텐츠운영 정보 및 안내 문구 변경
투어맵시설 위치 변경, 임시 통제 구역 반영
공지사항긴급 안내, 교통 통제, 운영 변경
메인 배너주요 홍보 내용 변경
스탬프 투어수집 지점 및 운영 조건 점검

주의사항

운영 중인 콘텐츠를 수정하면 방문객이 확인하는 정보에도 영향을 줄 수 있습니다.

중요한 내용을 변경한 경우 저장 후 실제 안내 페이지에서 정상적으로 표시되는지 확인해 주세요.

9.6. 공지사항을 통한 운영 정보 안내 ​

행사 운영 중 발생하는 주요 변경 사항은 공지사항을 통해 방문객에게 안내할 수 있습니다.

① 공지사항 등록 ​

  1. 공지사항 메뉴로 이동합니다.
  2. 안내할 내용을 입력합니다.
  3. 추가 버튼을 클릭합니다.
  4. 현재 노출 중인 공지사항 목록을 확인합니다.

② 운영 중 공지사항 활용 예시 ​

상황공지사항 예시
공연 시간 변경현장 상황으로 인해 메인 공연이 오후 4시부터 진행됩니다.
시설 이용 제한안전 점검으로 인해 동측 출입구 이용이 일시 제한됩니다.
교통 안내행사장 주변 교통 혼잡이 예상되오니 대중교통을 이용해 주세요.
운영 종료금일 체험 프로그램 접수가 마감되었습니다.

③ 공지사항 노출 종료 ​

안내가 더 이상 필요하지 않은 경우 해당 공지사항의 노출을 종료할 수 있습니다.

노출을 종료한 공지사항은 이력으로 보관되며 필요한 경우 다시 노출할 수 있습니다.

자세한 내용은 5.5. 공지사항 등록 및 관리를 참고해 주세요.

9.7. 행사 종료 후 프로젝트 관리 ​

행사가 종료된 후에는 프로젝트 상태와 주요 콘텐츠를 확인하여 안내 페이지를 정리할 수 있습니다.

① 행사 종료 후 확인사항 ​

  • 행사 일정 및 프로그램 운영 종료 여부
  • 노출 중인 공지사항
  • 스탬프 투어 및 보상 운영 종료 여부
  • 설문조사 운영 기간
  • 안내 페이지 운영 유지 여부

② 프로젝트 비활성화 ​

방문객용 안내 페이지 운영을 종료할 경우 프로젝트를 비활성화할 수 있습니다.

설정 방법

  1. 프로젝트 관리 화면으로 이동합니다.
  2. 프로젝트 설정 > 기본 정보를 선택합니다.
  3. 프로젝트 상태를 비활성화로 변경합니다.
  4. 변경 내용을 저장합니다.
  5. 방문객용 안내 페이지의 접속 상태를 확인합니다.

주의사항

프로젝트 비활성화는 방문객의 서비스 이용에 영향을 줄 수 있습니다.

행사 종료 후에도 일정 기간 정보를 제공해야 하는 경우 운영 종료 일정과 공개 유지 여부를 확인한 후 변경해 주세요.

9.8. 운영 전 최종 체크리스트 ​

프로젝트를 방문객에게 공개하기 전에 아래 항목을 최종 점검해 주세요.

프로젝트 설정

  • 프로젝트 기본 정보 및 운영 기간 확인
  • 프로젝트 상태 확인
  • 로고, 색상 및 글꼴 확인
  • 지원 언어 및 서비스 모듈 확인
  • 하단 내비게이션 및 최초 진입 화면 확인

콘텐츠 및 서비스

  • 메인 배너 및 바로가기 링크 확인
  • 상세 콘텐츠 및 행사 일정 확인
  • 투어맵 및 지도 객체 표시 확인
  • 스탬프 투어와 보상 정책 확인
  • AI 챗봇 및 부가 서비스 동작 확인
  • 공지사항 확인

방문객 화면

  • 안내 페이지 URL 접속 확인
  • 모바일 화면 표시 확인
  • 주요 버튼과 연결 링크 확인
  • 다국어 콘텐츠 표시 확인
  • 실제 행사 운영 정보와 일치하는지 확인
