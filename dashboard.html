10. 대시보드 및 이용 통계 ​

인포디오는 축제 및 행사 안내 페이지의 이용 현황을 확인할 수 있는 통계 대시보드를 제공합니다.

프로젝트 운영자는 대시보드를 통해 방문객의 서비스 이용 현황, 시간대별 이용 추이, 기능별 사용 비율, 행사장 혼잡도 등을 확인할 수 있습니다.

이를 통해 행사 운영 상황을 파악하고 방문객의 이용 패턴을 분석하는 데 활용할 수 있습니다.

10.1. 대시보드 화면 구성 ​

대시보드는 프로젝트별 안내 페이지 이용 현황을 확인하는 관리 화면입니다.

① 대시보드 접속 ​

  1. CMS에 로그인합니다.
  2. 관리할 프로젝트를 선택합니다.
  3. 프로젝트 관리 화면에서 통계 대시보드 메뉴로 이동합니다.
  4. 해당 프로젝트의 이용 현황을 확인합니다.

② 대시보드 주요 구성 ​

구분설명
사용자 이용 현황동시 접속 사용자 수, 방문 사용자 수, 평균 앱 이용시간
누적 이용 현황누적 방문 사용자 수, 누적 접속량, 1인당 평균 사용량
5분 기반 추정 혼잡도최근 위치 데이터를 기반으로 한 행사장 내 상대적 밀집도
시간대별 활성 사용자선택한 기간의 시간대별 사용자 수
서비스 이용 현황서비스 기능별 이용 횟수 및 비율
실시간 주요 이벤트최근 발생한 서비스 이용 기록
최신 챗봇 질문 이력방문객이 AI 챗봇에 입력한 최근 질문

③ 통계 데이터 확인 ​

대시보드에는 실시간 데이터와 선택한 기간에 따른 이용 통계가 함께 표시됩니다.

실시간 데이터는 최신 운영 현황을 파악하는 데 활용하고, 기간별 통계는 특정 날짜나 행사 기간의 이용 패턴을 분석하는 데 활용할 수 있습니다.

참고

대시보드 상단에 데이터 갱신 시각이 표시됩니다.

실시간 통계는 데이터 처리 및 갱신 시점에 따라 실제 현장 상황과 약간의 차이가 발생할 수 있습니다.

10.2. 통계 조회 기간 설정 ​

대시보드에서는 날짜를 선택하여 특정 기간의 서비스 이용 통계를 확인할 수 있습니다.

① 조회 기간 선택 ​

  1. 통계 대시보드 화면 상단의 날짜 선택 영역을 클릭합니다.
  2. 조회할 시작일과 종료일을 선택합니다.
  3. 선택한 기간의 통계가 표시되는지 확인합니다.

② 조회 기간 적용 범위 ​

조회 기간은 다음 항목에 적용됩니다.

통계 항목날짜 선택 적용 여부
방문 사용자 수적용
평균 앱 이용시간적용
시간대별 활성 사용자적용
서비스 이용 현황적용
동시 접속 사용자 수(5분)미적용
5분 기반 추정 혼잡도미적용
실시간 주요 이벤트미적용
최신 챗봇 질문 이력미적용
누적 이용 현황미적용

주의사항

날짜 선택은 기간별 이용 통계에만 적용됩니다.

실시간 접속 현황, 혼잡도 및 주요 이벤트는 선택한 날짜와 관계없이 최신 데이터를 표시합니다.

10.3. 사용자 이용 현황 확인 ​

사용자 이용 현황은 안내 페이지를 이용하는 방문객의 수와 이용시간을 확인할 수 있는 영역입니다.

① 동시 접속 사용자 수(5분) ​

최근 5분 동안 안내 페이지를 이용한 사용자 수를 표시합니다.

예를 들어 '동시 접속 사용자 수(5분)'가 150명으로 표시된다면 최근 5분 이내 서비스를 이용한 사용자가 150명이라는 의미입니다.

해당 수치는 정확히 같은 순간에 화면을 보고 있는 사용자 수가 아닌 최근 5분간 활동한 사용자 수를 의미합니다.

② 방문 사용자 수 ​

선택한 기간 동안 안내 페이지를 한 번 이상 이용한 사용자 수를 표시합니다.

예를 들어 동일한 방문객이 하루 동안 여러 번 접속하더라도 방문 사용자 수에서는 한 명의 사용자로 집계됩니다.

③ 평균 앱 이용시간 ​

사용자가 안내 페이지에 접속하여 평균적으로 이용한 시간을 표시합니다.

서비스 이용 기록을 기준으로 계산하며, 30분 이상 이용 기록이 없는 경우 새로운 접속으로 구분하여 계산합니다.

④ 통계 활용 예시 ​

확인할 지표활용 목적
동시 접속 사용자 수현재 서비스 이용 규모 파악
방문 사용자 수행사 안내 페이지의 이용 규모 확인
평균 앱 이용시간방문객의 서비스 이용 지속 시간 분석

참고

통계는 안내 페이지의 서비스 이용 기록을 기준으로 집계됩니다.

실제 행사장에 입장한 전체 방문객 수와는 차이가 있을 수 있습니다.

10.4. 누적 이용 현황 확인 ​

누적 이용 현황에서는 행사 기간 동안의 전체 서비스 이용 규모를 확인할 수 있습니다.

① 누적 이용 지표 ​

항목설명
누적 방문 사용자수행사 기간 동안 안내 페이지를 한 번 이상 이용한 사용자 수
누적 접속량행사 기간 동안 사용자가 안내 페이지의 기능을 이용한 총 횟수
1인당 평균 사용량사용자 한 명당 평균 서비스 기능 이용 횟수

② 지표 확인 방법 ​

  1. 통계 대시보드에 접속합니다.
  2. 누적 이용 현황 영역을 확인합니다.
  3. 각 지표의 수치를 확인합니다.
  4. 지표명 옆의 도움말을 통해 집계 기준을 확인할 수 있습니다.

③ 누적 이용 현황 활용 ​

누적 방문 사용자 수와 누적 접속량을 함께 확인하면 행사 안내 페이지의 전체 이용 규모와 서비스 활용 정도를 파악할 수 있습니다.

예를 들어 누적 방문 사용자 수에 비해 누적 접속량이 높다면 방문객이 여러 기능을 반복적으로 이용하고 있을 가능성이 있습니다.

참고

1인당 평균 사용량은 앱 접속 기능을 제외한 서비스 기능 이용 횟수를 기준으로 계산합니다.

10.5. 5분 기반 추정 혼잡도 확인 ​

5분 기반 추정 혼잡도는 방문객의 위치 정보를 이용하여 행사장 내 상대적인 밀집도를 지도에 표시하는 기능입니다.

최근 5분 이내 위치 정보를 전송한 사용자의 마지막 위치를 기준으로 혼잡도를 표현합니다.

① 혼잡도 지도 확인 ​

  1. 통계 대시보드의 5분 기반 추정 혼잡도 영역으로 이동합니다.
  2. 지도에 표시된 혼잡도 분포를 확인합니다.
  3. 필요한 경우 지도를 확대하거나 이동하여 특정 지역을 확인합니다.

② 혼잡도 표시 방식 ​

혼잡도는 위치 정보가 수집된 방문객들의 상대적인 밀집 수준을 색상으로 표현합니다.

지도에서 상대적으로 밀집도가 높은 영역과 낮은 영역을 시각적으로 구분할 수 있습니다.

활용 예시

  • 행사장 내 방문객 밀집 구역 파악
  • 특정 공연장 주변의 이용자 집중 현상 확인
  • 주요 이동 동선의 상대적인 혼잡 수준 확인
  • 행사장 운영 상황 파악을 위한 참고 자료 활용

③ 혼잡도 지도 확대 ​

혼잡도 지도를 더 크게 확인하려면 확대 기능을 이용할 수 있습니다.

설정 방법

  1. 혼잡도 영역의 확대 버튼을 클릭합니다.
  2. 확대된 지도에서 행사장 구역을 확인합니다.
  3. 필요한 경우 지도를 이동하거나 확대하여 확인합니다.
  4. 축소 버튼을 클릭하여 기존 화면으로 돌아갑니다.

주의사항

혼잡도는 최근 위치 정보를 전송한 사용자만을 기준으로 계산한 추정 데이터입니다.

실제 행사장에 있는 전체 인원을 나타내는 수치가 아니며, 방문객의 위치 정보 제공 여부와 위치 정확도 등에 따라 차이가 발생할 수 있습니다.

따라서 정확한 현장 인원 집계나 안전 관리 판단의 유일한 기준으로 사용하지 않는 것을 권장합니다.

10.6. 시간대별 활성 사용자 확인 ​

시간대별 활성 사용자 통계는 선택한 기간 동안 안내 페이지를 이용한 사용자 수를 시간대별로 보여주는 기능입니다.

특정 시간에 서비스 이용이 집중되는지 확인할 수 있습니다.

① 시간대별 통계 확인 ​

  1. 대시보드 상단에서 조회 기간을 선택합니다.
  2. 시간대별 활성 사용자 영역으로 이동합니다.
  3. 시간대별로 표시된 그래프를 확인합니다.
  4. 특정 시간대의 그래프에 마우스를 올리거나 해당 값을 선택하여 사용자 수를 확인합니다.

② 통계 활용 예시 ​

확인 사항활용 목적
이용자가 많은 시간대주요 서비스 이용 집중 시간 확인
이용자가 적은 시간대서비스 이용이 상대적으로 적은 시간 확인
시간대별 이용 변화행사 일정과 서비스 이용 흐름 비교

참고

활성 사용자 수는 해당 시간대에 안내 페이지를 한 번 이상 이용한 사용자를 기준으로 집계됩니다.

실제 행사장 방문 인원과는 차이가 있을 수 있습니다.

10.7. 서비스 이용 현황 확인 ​

서비스 이용 현황은 방문객이 안내 페이지에서 어떤 기능을 많이 사용하는지 확인할 수 있는 통계입니다.

각 서비스의 이용 횟수와 전체 이용량 대비 비율을 도넛 차트로 표시합니다.

① 서비스 이용 현황 확인 ​

  1. 대시보드 상단에서 조회 기간을 선택합니다.
  2. 서비스 이용 현황 영역으로 이동합니다.
  3. 기능별 이용 비율과 횟수를 확인합니다.

② 서비스 이용 통계 항목 ​

프로젝트에서 사용하는 기능에 따라 다음과 같은 이용 기록을 확인할 수 있습니다.

기능설명
홈홈 화면 관련 이용 기록
투어맵지도 이용 및 상호작용 기록
일정일정 화면 이용 기록
AI 챗봇챗봇 서비스 이용 기록
스탬프 투어스탬프 관련 이용 기록
설문설문 서비스 이용 기록
상세 콘텐츠상세 페이지 조회 기록
바로가기바로가기 기능 이용 기록

실제 표시 항목은 프로젝트에서 활성화한 기능과 수집된 이용 기록에 따라 달라질 수 있습니다.

③ 서비스 이용 현황 활용 ​

서비스 이용 현황은 다음과 같은 목적으로 활용할 수 있습니다.

  • 방문객이 많이 사용하는 기능 파악
  • 안내 페이지에서 관심도가 높은 콘텐츠 유형 확인
  • 사용량이 적은 서비스 기능 검토
  • 행사 종료 후 운영 성과 분석

참고

서비스 이용 비율은 선택한 기간에 발생한 기능별 이벤트를 기준으로 계산하며, 앱 접속 이벤트는 제외됩니다.

이용 횟수는 사용자 수와 다를 수 있습니다. 한 명의 사용자가 같은 기능을 여러 번 이용하면 이용 횟수에 중복 반영될 수 있습니다.

10.8. 실시간 주요 이벤트 확인 ​

실시간 주요 이벤트는 방문객이 최근 안내 페이지에서 이용한 기능이나 행동에 대한 기록을 보여주는 영역입니다.

운영자는 이를 통해 최근 어떤 서비스가 이용되고 있는지 확인할 수 있습니다.

① 주요 이벤트 목록 확인 ​

  1. 통계 대시보드에서 실시간 주요 이벤트 영역으로 이동합니다.
  2. 최근 발생한 이벤트 목록을 확인합니다.
  3. 이벤트가 발생한 시간과 내용을 확인합니다.

② 이벤트 정보 ​

항목설명
시간이벤트가 발생한 시간
이벤트사용자가 이용한 기능이나 발생한 이벤트 내용

③ 이벤트 전체보기 ​

실시간 이벤트를 더 자세히 확인하려면 전체보기 기능을 이용합니다.

확인 방법

  1. 실시간 주요 이벤트 영역에서 전체보기 버튼을 클릭합니다.
  2. 별도의 브라우저 창에서 실시간 이벤트 목록을 확인합니다.
  3. 필요한 경우 창의 크기를 조정하여 이벤트 기록을 확인합니다.

참고

전체보기는 새로운 브라우저 창으로 실행됩니다.

창이 열리지 않는 경우 브라우저의 팝업 차단 설정을 확인해 주세요.

10.9. 최신 챗봇 질문 이력 확인 ​

최신 챗봇 질문 이력은 방문객이 AI 챗봇에 최근 입력한 질문을 확인할 수 있는 기능입니다.

운영자는 방문객이 자주 문의하는 내용이나 추가 안내가 필요한 정보를 파악하는 데 활용할 수 있습니다.

① 챗봇 질문 이력 확인 ​

  1. 통계 대시보드에서 최신 챗봇 질문 이력 영역으로 이동합니다.
  2. 최근 입력된 질문 목록을 확인합니다.
  3. 질문이 입력된 시간과 내용을 확인합니다.

② 질문 이력 정보 ​

항목설명
시간방문객이 챗봇에 질문을 입력한 시간
질문방문객이 실제 입력한 질문 내용

기본 화면에서는 최근 질문 일부가 표시되며, 확대 기능을 이용해 더 많은 질문을 확인할 수 있습니다.

③ 챗봇 질문 이력 확대 ​

  1. 최신 챗봇 질문 이력 영역의 확대 버튼을 클릭합니다.
  2. 확대된 목록에서 질문 내용을 확인합니다.
  3. 목록을 스크롤하여 추가 질문을 확인합니다.
  4. 축소 버튼을 클릭하여 기존 화면으로 돌아갑니다.

④ 질문 이력 활용 예시 ​

자주 입력되는 질문활용 방법

참고

최신 챗봇 질문 이력에서는 방문객이 입력한 질문을 확인할 수 있습니다.

질문 이력은 방문객의 정보 수요를 파악하는 참고 자료로 활용할 수 있으며, 개별 질문에 대한 답변의 정확성까지 보장하는 것은 아닙니다.

10.10. 대시보드 활용 및 주의사항 ​

대시보드는 행사 운영 상황을 파악하고 방문객의 서비스 이용 흐름을 분석하는 데 활용할 수 있습니다.

① 운영 중 활용 ​

  • 동시 접속 사용자 수를 통해 최근 서비스 이용 규모 확인
  • 혼잡도 지도를 통해 상대적으로 밀집된 구역 확인
  • 실시간 이벤트를 통해 주요 서비스 이용 기록 확인
  • 챗봇 질문 이력을 통해 자주 문의하는 정보 파악

② 행사 종료 후 활용 ​

  • 누적 방문 사용자 수 확인
  • 시간대별 서비스 이용 추이 분석
  • 기능별 이용 비율 확인
  • 향후 행사 운영 및 안내 콘텐츠 개선을 위한 참고 자료 활용

③ 통계 확인 시 유의사항 ​

이용자 수와 실제 방문객 수 구분

대시보드의 사용자 수는 안내 페이지의 이용 기록을 기준으로 하므로 실제 행사장 입장객 수와 동일하지 않을 수 있습니다.

이벤트 수와 사용자 수 구분

서비스 이용 횟수는 동일한 사용자의 반복 이용을 포함할 수 있으므로 실제 사용자 수와 다를 수 있습니다.

혼잡도 데이터 해석

혼잡도는 위치 정보 제공 사용자를 기준으로 계산한 추정 데이터이므로 실제 현장 밀집 인원을 정확하게 나타내지는 않습니다.

실시간 데이터와 기간별 통계 구분

실시간 통계와 날짜별 통계는 집계 기준이 다르므로 비교 시 각 지표의 설명을 확인해 주세요.

④ 최종 확인 항목 ​

  • 올바른 프로젝트의 통계를 확인하고 있는지 점검
  • 조회 기간이 분석 목적에 맞게 설정되었는지 확인
  • 실시간 통계와 기간별 통계의 차이 확인
  • 방문 사용자 수와 누적 방문 사용자 수 구분
  • 서비스 이용 비율 및 이벤트 수 확인
  • 혼잡도 지도의 추정 데이터 기준 확인
  • 최신 챗봇 질문 이력 확인
