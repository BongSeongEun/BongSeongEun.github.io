3. 프로젝트 설정 및 관리 ​

인포디오에서는 축제 및 행사별로 독립적인 프로젝트를 운영할 수 있습니다.

프로젝트는 인포디오 운영사에서 생성하여 고객사에 제공하며, 고객사는 할당받은 프로젝트의 기본 정보, 디자인, 서비스 기능 및 하단 내비게이션 등을 직접 설정할 수 있습니다.

본 장에서는 프로젝트를 전달받은 후 안내 페이지 운영을 위해 필요한 초기 설정 방법을 안내합니다.

3.1. 프로젝트 관리 화면 진입 ​

CMS에서 설정할 프로젝트를 선택하여 관리 화면으로 이동합니다.

① 프로젝트 선택 ​

  1. CMS에 로그인합니다.
  2. 프로젝트 관리 화면에서 할당된 프로젝트를 확인합니다.
  3. 관리할 프로젝트의 관리 버튼을 클릭합니다.
  4. 프로젝트 관리 화면으로 이동합니다.

3.2. 프로젝트 기본 정보 설정 ​

프로젝트 관리 화면에서 프로젝트 설정(Project Setting) 메뉴로 이동하여 프로젝트의 행사명, 행사 기간, 운영 상태 및 담당자 정보를 확인하고 수정할 수 있습니다.

① 기본 정보 설정 ​

  1. 상단의 기본 정보 항목을 선택합니다.
  2. 변경할 정보를 입력합니다.
  3. 화면 상단의 저장 버튼을 클릭합니다.

항목설명변경 가능 여부
행사명축제 또는 행사의 이름가능
슬러그(URL)안내 페이지에 사용되는 접속 주소불가
행사 기간행사 시작일 및 종료일가능
상태프로젝트 운영 상태가능
담당자 정보이름, 소속, 직책 및 연락처가능

주의사항

슬러그(URL)는 프로젝트 생성 시 설정되며, 고객사는 직접 변경할 수 없습니다.

접속 주소 변경이 필요한 경우 인포디오 운영사에 문의해 주세요.

3.3. 프로젝트 브랜딩 설정 ​

브랜딩 설정에서는 안내 페이지에 적용할 로고, 대표 색상, 강조 색상 및 글꼴을 변경할 수 있습니다.

축제 또는 행사의 브랜드 이미지에 맞는 디자인을 적용하여 방문객에게 일관된 화면을 제공할 수 있습니다.

① 브랜딩 설정 화면 이동 ​

  1. 프로젝트 관리 화면에서 프로젝트 설정 메뉴로 이동합니다.
  2. 상단의 브랜딩 항목을 선택합니다.
  3. 현재 적용된 로고, 색상 및 글꼴을 확인합니다.

② 로고 설정 ​

안내 페이지에서 사용할 로고 또는 심볼 이미지를 등록할 수 있습니다.

설정 방법

  1. 로고 / 심볼 이미지 항목으로 이동합니다.
  2. 이미지 파일을 선택하여 등록합니다.
  3. 기존 로고가 있는 경우 첨부 파일 변경을 통해 변경합니다.
  4. 설정을 저장합니다.

③ 테마 색상 설정 ​

안내 페이지에 적용할 대표 색상과 강조 색상을 설정합니다.

항목설명
Primary Color주요 버튼 등의 배경에 사용되는 대표 색상
Accent Color일부 강조 요소에 사용되는 색상

설정 방법

  1. 테마 색상 항목으로 이동합니다.
  2. Primary Color와 Accent Color를 설정합니다.
  3. 색상 적용 결과를 확인합니다.
  4. 설정을 저장합니다.

Primary Color는 그라데이션 설정을 지원합니다.

참고

배경과 글자의 명도 차이가 충분한 색상을 선택하는 것을 권장합니다. 특히 주요 버튼의 색상은 흰색 텍스트와 구분되도록 설정하는 것이 좋습니다.

④ 글꼴 설정 ​

안내 페이지에 적용할 글꼴을 선택할 수 있습니다.

기본적으로 다음 글꼴을 제공합니다.

글꼴설명
SUIT간결하고 현대적인 형태의 글꼴
Pretendard다양한 화면에서 가독성이 높은 글꼴

별도의 글꼴이 필요한 경우 사용자 정의 글꼴을 설정할 수 있습니다.

사용자 정의 글꼴은 CDN 주소 또는 글꼴 파일을 이용하여 등록할 수 있습니다.

설정이 완료되면 화면 상단의 저장 버튼을 클릭합니다.

3.4. 서비스 모듈 설정 ​

서비스 모듈은 안내 페이지에서 제공할 개별 기능을 의미합니다.

행사의 운영 목적에 따라 필요한 모듈을 활성화하거나 사용하지 않는 모듈을 비활성화할 수 있습니다.

① 모듈 설정 화면 이동 ​

  1. 프로젝트 설정 메뉴로 이동합니다.
  2. 상단의 모듈 항목을 선택합니다.
  3. 현재 활성화된 서비스 모듈을 확인합니다.

② 서비스 모듈 안내 ​

모듈설명
홈행사 소개 및 주요 콘텐츠 제공
투어맵행사 장소 및 시설의 위치 안내
일정행사 및 프로그램 일정 안내
AI 챗봇대화형 행사 정보 안내
스탬프 투어스탬프 수집 및 방문객 참여 기능
설문방문객 설문조사
비디오 가이드영상 기반 안내 콘텐츠
오디오 가이드음성 기반 안내 콘텐츠

③ 모듈 활성화 및 비활성화 ​

  1. 모듈 목록에서 사용할 기능을 확인합니다.
  2. 활성화할 모듈의 체크박스를 선택합니다.
  3. 사용하지 않을 모듈은 체크를 해제합니다.
  4. 화면 상단의 저장 버튼을 클릭합니다.

모듈 비활성화 시 유의사항

모듈을 비활성화하면 해당 기능이 숨김 처리되지만, 기존에 입력한 데이터는 삭제되지 않습니다.

따라서 일시적으로 사용하지 않는 기능은 데이터를 삭제하지 않고 비활성화할 수 있습니다.

참고

모듈을 활성화하더라도 해당 기능에 필요한 콘텐츠나 세부 설정이 완료되지 않았다면 방문객이 정상적으로 이용하기 어려울 수 있습니다.

기능을 활성화한 후에는 해당 모듈의 관리 메뉴에서 필요한 정보를 등록해 주세요.

3.5. 하단 내비게이션 설정 ​

하단 내비게이션은 방문객용 안내 페이지의 하단에 표시되는 주요 메뉴입니다.

사용할 메뉴와 표시 순서, 최초 진입 화면 및 스타일을 설정할 수 있습니다.

① 하단 내비게이션 설정 화면 이동 ​

  1. 프로젝트 관리 화면에서 바텀 네비게이션 메뉴를 선택합니다.

  2. 현재 설정된 메뉴 목록을 확인합니다.

  3. 필요한 항목을 수정합니다.

② 하단 메뉴 구성 ​

하단 내비게이션에 표시할 메뉴를 선택하고 표시 순서를 설정합니다.

설정 방법

  1. 메뉴 목록에서 표시할 항목을 선택합니다.
  2. 메뉴 순서를 조정합니다.
  3. 필요한 경우 메뉴별 아이콘을 설정합니다.
  4. 변경 결과를 미리보기에서 확인합니다.

③ 최초 진입 화면 설정 ​

최초 진입 화면(랜딩 페이지)은 방문객이 안내 페이지에 접속했을 때 처음 표시되는 화면입니다.

메뉴 중 한개 항목을 랜딩으로 선택하게 되면, 행사 목적에 맞게 적절한 시작 화면을 선택할 수 있습니다.

예를 들어 행사 정보를 먼저 안내해야 한다면 홈을, 행사장 위치 안내가 중요하다면 투어맵을 시작 화면으로 설정할 수 있습니다.

④ 하단 내비게이션 스타일 설정 ​

하단 메뉴의 표시 스타일을 설정할 수 있습니다.

설정 화면에서 제공되는 스타일 옵션을 선택하고, 미리보기를 통해 적용 결과를 확인합니다.

설정을 마친 후 화면 상단의 저장 버튼을 클릭합니다.

참고

하단 내비게이션 설정은 프로젝트의 서비스 모듈 설정과 구분됩니다.

서비스 모듈에서는 기능의 사용 여부를 설정하고, 바텀 네비게이션에서는 방문객에게 표시할 메뉴와 순서 등을 설정합니다.

3.6. 다국어 설정 ​

인포디오는 다양한 언어를 사용하는 방문객에게 행사 정보를 제공할 수 있도록 다국어 기능을 지원합니다.

프로젝트 운영자는 행사 특성과 방문객의 언어 환경에 맞게 기본 언어와 지원 언어를 설정할 수 있습니다.

① 다국어 설정 화면 이동 ​

  1. 프로젝트 관리 화면에서 프로젝트 설정 메뉴로 이동합니다.
  2. 상단의 다국어 항목을 선택합니다.
  3. 현재 설정된 기본 언어 및 지원 언어를 확인합니다.

② 기본 언어 설정 ​

기본 언어는 방문객용 안내 페이지에서 기본적으로 사용되는 언어입니다.

프로젝트의 주요 방문객에 맞춰 기본 언어를 선택합니다.

③ 지원 언어 설정 ​

방문객에게 제공할 언어를 선택합니다.

프로젝트에서 지원하는 언어는 다음과 같습니다.

언어언어 코드
한국어ko
영어en
일본어ja
중국어zh
태국어th

설정 방법

  1. 지원할 언어를 선택합니다.
  2. 기본 언어를 지정합니다.
  3. 변경된 설정을 확인합니다.
  4. 저장 버튼을 클릭합니다.

참고

지원 언어를 추가한 경우 각 언어에 맞는 콘텐츠를 등록해야 할 수 있습니다.

방문객에게 제공할 언어별 콘텐츠가 올바르게 표시되는지 확인해 주세요.

④ 다국어 설정 확인 ​

설정 완료 후 방문객용 안내 페이지에 접속하여 언어 선택 및 콘텐츠 표시 상태를 확인합니다.

3.7. 초기 설정 확인 ​

프로젝트의 기본 정보, 브랜딩, 모듈 및 하단 내비게이션 설정을 완료한 후에는 방문객용 안내 페이지를 확인합니다.

확인 항목 ​

  • 행사명과 행사 기간이 정확하게 등록되어 있는지 확인
  • 프로젝트 운영 상태가 적절하게 설정되어 있는지 확인
  • 로고와 테마 색상이 올바르게 적용되었는지 확인
  • 선택한 글꼴이 정상적으로 표시되는지 확인
  • 필요한 서비스 모듈이 활성화되어 있는지 확인
  • 하단 메뉴와 표시 순서가 올바른지 확인
  • 최초 진입 화면이 의도한 화면으로 설정되어 있는지 확인
  • 모바일 환경에서 안내 페이지가 정상적으로 표시되는지 확인

초기 설정이 완료되면 메인 배너, 상세 콘텐츠, 행사 일정, 지도 등의 정보를 등록하여 안내 페이지를 구성할 수 있습니다.

자세한 내용은 4. 안내 페이지 디자인 및 기본 화면 설정에서 안내합니다.
