5. 행사 콘텐츠 등록 및 관리 ​

인포디오에서는 축제 및 행사와 관련된 다양한 정보를 콘텐츠로 등록하여 방문객에게 제공할 수 있습니다.

프로젝트 운영자는 CMS에서 행사 소개, 프로그램 안내, 행사 일정, 공지사항 등을 직접 등록하고 관리할 수 있습니다.

등록한 콘텐츠는 서비스 구성에 따라 방문객용 안내 페이지에서 제공되며, 행사 운영 중에도 내용을 수정할 수 있습니다.

5.1. 콘텐츠 관리 기능 안내 ​

CMS에서 제공하는 주요 콘텐츠 관리 기능은 다음과 같습니다.

관리 기능설명
상세 콘텐츠행사 및 프로그램의 상세 정보, 이미지, 안내 문구 등을 등록하고 관리
일정공연, 체험, 전시 등 행사 프로그램의 일정 관리
일정 카테고리일정의 유형을 구분하는 카테고리 관리
일정 배지일정에 표시할 강조 문구 및 배지 관리
공지사항방문객에게 전달할 주요 공지사항 관리

콘텐츠 등록 권장 순서 ​

  1. 일정 카테고리 및 배지 설정
  2. 상세 콘텐츠 등록
  3. 행사 일정 등록 및 상세 콘텐츠 연결
  4. 공지사항 등록
  5. 방문객용 안내 페이지에서 표시 상태 확인

5.2. 상세 콘텐츠 등록 및 관리 ​

상세 콘텐츠는 방문객에게 행사, 프로그램, 시설 등의 정보를 자세하게 안내하기 위한 기능입니다.

제목, 설명, 이미지, 주요 정보, 상세 일정 등을 등록하여 하나의 안내 페이지로 구성할 수 있습니다.

예를 들어 공연 소개, 체험 프로그램 안내, 부스 이용 안내 등에 활용할 수 있습니다.

① 상세 콘텐츠 관리 화면 이동 ​

  1. 프로젝트 관리 화면에서 상세 콘텐츠 메뉴를 선택합니다.
  2. 등록된 콘텐츠 목록을 확인합니다.
  3. 신규 콘텐츠를 등록하려면 콘텐츠 추가 화면으로 이동합니다.

② 기본 정보 입력 ​

상세 콘텐츠의 기본 정보를 입력합니다.

항목설명
제목상세 콘텐츠의 이름
URL콘텐츠에 부여된 개별 접근 주소
부제제목 아래 표시할 보조 문구
설명방문객에게 제공할 콘텐츠 소개 문구

등록 방법

  1. 상세 콘텐츠 추가 화면으로 이동합니다.
  2. 제목을 입력합니다.
  3. 필요한 경우 부제를 입력합니다.
  4. 설명에 콘텐츠의 주요 내용을 작성합니다.
  5. 다른 콘텐츠 구성 항목을 설정합니다.

참고

제목은 방문객이 콘텐츠의 내용을 쉽게 이해할 수 있도록 작성하는 것이 좋습니다.

예를 들어 '프로그램 01'보다는 '전통 공예 체험 프로그램'처럼 구체적인 명칭을 사용하는 것을 권장합니다.

③ 배너 이미지 및 미디어 설정 ​

상세 콘텐츠 상단에 표시할 이미지나 영상 콘텐츠를 등록합니다.

배너 영역은 상세 콘텐츠의 주요 시각 자료를 보여주는 영역입니다.

설정 방법

  1. 배너 영역으로 이동합니다.
  2. 등록할 미디어 유형을 선택합니다.
  3. 이미지 또는 영상 관련 정보를 등록합니다.
  4. 추가된 미디어를 확인합니다.

참고

배너 영역은 상세 콘텐츠의 주요 정보를 전달하는 필수 구성 영역입니다.

이미지는 내용에 적합하고 해상도가 충분한 파일을 사용하는 것을 권장합니다.

④ 주요 정보 등록 ​

주요 정보 영역에서는 콘텐츠와 관련된 정보를 항목별로 등록할 수 있습니다.

예를 들어 운영 시간, 이용 요금, 문의처 등 방문객이 알아야 할 정보를 구성할 수 있습니다.

항목명 예시내용 예시
운영 시간10:00 ~ 18:00
이용 요금무료
참여 대상누구나 참여 가능
문의현장 안내소

설정 방법

  1. 주요 정보 영역으로 이동합니다.
  2. 항목 추가 버튼을 클릭합니다.
  3. 항목명과 내용을 입력합니다.
  4. 필요한 만큼 항목을 추가합니다.
  5. 불필요한 항목은 삭제합니다.

⑤ 상세 일정 등록 ​

상세 콘텐츠에 관련된 일정이 있다면 상세 일정을 추가할 수 있습니다.

예를 들어 하나의 공연 프로그램에 여러 회차의 공연 시간이 있다면 회차별 일정을 구성할 수 있습니다.

설정 방법

  1. 상세 콘텐츠 편집 화면에서 상세 일정 영역으로 이동합니다.
  2. 상세 일정 추가 버튼을 클릭합니다.
  3. 일정 정보를 입력합니다.
  4. 일정 등록을 완료합니다.
  5. 상세 일정 목록에 추가된 내용을 확인합니다.

⑥ 하단 액션 버튼 설정 ​

상세 콘텐츠 하단에 별도의 이동 버튼을 표시할 수 있습니다.

이 버튼은 방문객을 외부 사이트나 관련 페이지로 이동시키는 용도로 사용할 수 있습니다.

항목설명
공개하단 버튼 표시 여부
버튼 텍스트버튼에 표시할 문구
연결 링크버튼 클릭 시 이동할 주소 또는 페이지

설정 방법

  1. 하단 액션 버튼 영역으로 이동합니다.
  2. 버튼 공개 여부를 설정합니다.
  3. 버튼 텍스트를 입력합니다.
  4. 이동할 링크를 설정합니다.
  5. 변경 내용을 저장합니다.

⑦ 상세 콘텐츠 수정 및 삭제 ​

등록된 상세 콘텐츠는 목록에서 선택하여 내용을 수정할 수 있습니다.

수정 방법

  1. 상세 콘텐츠 목록에서 수정할 콘텐츠를 선택합니다.
  2. 변경할 정보를 수정합니다.
  3. 저장 버튼을 클릭합니다.

콘텐츠 삭제가 필요한 경우에는 삭제 기능을 이용합니다.

주의사항

상세 콘텐츠가 일정이나 지도 등 다른 기능과 연결되어 있다면 삭제 시 연결된 화면에 영향을 줄 수 있습니다.

삭제 전 콘텐츠의 사용 여부를 확인해 주세요.

5.3. 행사 일정 등록 및 관리 ​

일정 관리 기능은 공연, 전시, 체험 프로그램 등 축제에서 진행되는 다양한 행사의 날짜와 시간을 등록하고 관리하는 기능입니다.

등록된 일정은 방문객용 안내 페이지의 일정 화면에 표시되며, 일정별 카테고리, 배지, 장소 및 관련 콘텐츠를 설정할 수 있습니다.

① 일정 관리 화면 이동 ​

  1. 프로젝트 관리 화면에서 전체 일정 메뉴를 선택합니다.
  2. 일정 관리 화면에서 등록된 일정을 확인합니다.
  3. 새로운 일정을 등록하려면 일정 추가 기능을 선택합니다.

② 신규 일정 등록 ​

일정 추가 화면에서는 다음 정보를 입력할 수 있습니다.

항목설명
이름방문객에게 표시할 일정 또는 프로그램 이름
시작일 및 시간일정이 시작되는 날짜와 시간
종료일 및 시간일정이 종료되는 날짜와 시간
종일/상시특정 시간에 제한되지 않는 일정 설정
기간 내 반복설정한 기간 동안 지정된 시간에 반복되는 일정
이미지일정에 표시할 대표 이미지
장소프로그램이 진행되는 장소
카테고리일정의 유형을 구분하는 분류
배지일정에 표시할 강조 표시
관련 콘텐츠일정과 연결할 상세 콘텐츠

등록 방법

  1. 일정 추가 버튼을 클릭합니다.
  2. 일정 이름을 입력합니다.
  3. 시작일과 종료일을 설정합니다.
  4. 필요한 경우 종일/상시 또는 기간 내 반복을 설정합니다.
  5. 이미지와 장소를 등록합니다.
  6. 카테고리 및 배지를 선택합니다.
  7. 연결할 상세 콘텐츠가 있다면 선택합니다.
  8. 저장 버튼을 클릭합니다.

③ 종일/상시 일정 설정 ​

특정 시간 없이 운영되는 행사나 프로그램은 종일/상시 옵션을 이용하여 설정할 수 있습니다.

예를 들어 행사 기간 동안 계속 운영되는 전시, 체험 공간 등에 활용할 수 있습니다.

④ 기간 내 반복 일정 설정 ​

일정이 여러 날짜에 걸쳐 동일한 시간에 반복되는 경우 기간 내 반복 기능을 사용할 수 있습니다.

예를 들어 10월 15일부터 10월 17일까지 매일 14:00~15:00에 진행되는 프로그램을 등록할 수 있습니다.

설정 항목입력 예시
시작일2026-10-15
종료일2026-10-17
시작 시간14:00
종료 시간15:00
기간 내 반복활성화

위와 같이 설정하면 지정한 기간 동안 매일 동일한 시간에 진행되는 일정으로 구성할 수 있습니다.

⑤ 상세 콘텐츠 연결 ​

일정에는 기존에 등록한 상세 콘텐츠를 연결할 수 있습니다.

이를 통해 방문객이 일정 정보를 확인한 후 관련 프로그램의 상세 안내를 확인할 수 있습니다.

설정 방법

  1. 일정 추가 또는 편집 화면에서 관련 콘텐츠 항목으로 이동합니다.
  2. 연결할 상세 콘텐츠를 검색합니다.
  3. 원하는 콘텐츠를 선택합니다.
  4. 설정을 저장합니다.

참고

연결할 상세 콘텐츠가 없다면 먼저 상세 콘텐츠를 등록한 후 일정을 설정하는 것이 편리합니다.

⑥ 일정 수정 및 삭제 ​

일정 수정

  1. 일정 관리 화면에서 변경할 일정을 선택합니다.
  2. 일정 편집 화면에서 필요한 정보를 수정합니다.
  3. 저장 버튼을 클릭합니다.

일정 삭제

  1. 일정 관리 화면에서 삭제할 일정을 찾습니다.
  2. 삭제 기능을 선택합니다.
  3. 삭제할 일정 정보를 확인합니다.
  4. 삭제를 진행합니다.

5.4. 일정 카테고리 및 배지 관리 ​

일정 카테고리와 배지는 방문객이 다양한 행사 일정을 쉽게 구분할 수 있도록 지원하는 기능입니다.

카테고리는 일정의 유형을 분류하는 데 사용되며, 배지는 특정 일정의 특징이나 중요 정보를 강조하는 데 사용됩니다.

① 일정 카테고리 관리 ​

일정 카테고리는 방문객용 일정 화면 상단의 탭 메뉴에 표시됩니다.

예를 들어 공연, 체험, 전시 등으로 일정을 분류할 수 있습니다.

카테고리 등록 방법

  1. 프로젝트 관리 화면에서 일정 카테고리/배지 메뉴로 이동합니다.
  2. 카테고리 관리 영역을 확인합니다.
  3. 카테고리 이름을 입력합니다.
  4. 추가 버튼을 클릭합니다.
  5. 필요한 카테고리를 모두 등록합니다.
  6. 저장 버튼을 클릭합니다.

카테고리 구성 예시

카테고리해당 프로그램 예시
공연개막식, 버스킹, 특별 공연
체험공예 체험, 참여 프로그램
전시미술 전시, 특별 전시
기타부대 행사 및 기타 프로그램

등록한 카테고리는 드래그하여 표시 순서를 변경할 수 있습니다.

주의사항

카테고리를 삭제하면 해당 카테고리로 분류되었던 일정은 미분류 상태로 변경될 수 있습니다.

카테고리를 삭제하기 전 관련 일정을 확인해 주세요.

② 일정 배지 관리 ​

일정 배지는 행사 일정에 특정 특징을 표시할 때 사용하는 기능입니다.

예를 들어 '무료', '인기', '사전예약' 등의 배지를 만들어 활용할 수 있습니다.

배지 등록 방법

  1. 일정 카테고리/배지 메뉴에서 배지 관리 영역으로 이동합니다.
  2. 배지 이름을 입력합니다.
  3. 추가 버튼을 클릭합니다.
  4. 필요한 배지를 추가합니다.
  5. 저장 버튼을 클릭합니다.

배지 활용 예시

배지활용 목적
무료무료 참여 프로그램 안내
인기주요 인기 프로그램 강조
사전예약예약이 필요한 프로그램 안내
현장접수현장에서 신청하는 프로그램 안내

배지를 등록한 후 일정 편집 화면에서 해당 배지를 선택하여 적용할 수 있습니다.

5.5. 공지사항 등록 및 관리 ​

공지사항은 행사 운영과 관련된 중요한 정보를 방문객에게 전달하기 위한 기능입니다.

행사 시간 변경, 운영 안내, 긴급 공지 등 방문객에게 안내해야 하는 정보를 등록할 수 있습니다.

① 공지사항 관리 화면 이동 ​

  1. 프로젝트 관리 화면에서 공지사항 메뉴를 선택합니다.
  2. 현재 등록된 공지사항 목록을 확인합니다.
  3. 필요한 경우 새로운 공지사항을 등록합니다.

② 공지사항 등록 ​

등록 방법

  1. 공지사항 입력 영역에 안내할 내용을 입력합니다.
  2. 작성한 문구를 확인합니다.
  3. 추가 버튼을 클릭합니다.
  4. 등록된 공지사항을 확인합니다.

공지사항 작성 예시

상황공지사항 예시
행사 시간 변경우천으로 인해 야외 공연 시작 시간이 오후 3시로 변경되었습니다.
운영 안내행사장 입장 시 현장 안내요원의 안내에 따라 이동해 주세요.
시설 안내행사장 내 임시 화장실은 중앙 안내소 오른쪽에 마련되어 있습니다.
교통 안내행사장 주변 교통 혼잡이 예상되오니 가급적 대중교통을 이용해 주세요.

③ 공지사항 노출 순서 변경 ​

등록된 공지사항은 노출 순서를 변경할 수 있습니다.

설정 방법

  1. 공지사항 목록에서 순서를 변경할 항목을 확인합니다.
  2. 순서 변경 영역을 드래그합니다.
  3. 원하는 위치로 이동합니다.
  4. 변경된 순서를 확인합니다.

④ 공지사항 노출 및 이력 관리 ​

등록된 공지사항은 현재 노출 중인 공지사항과 노출이 종료된 공지사항으로 구분하여 관리할 수 있습니다.

노출이 종료된 공지사항은 완전히 삭제되지 않고 이력에 보관되므로, 필요한 경우 다시 노출할 수 있습니다.

공지사항 노출 종료 방법

  1. 공지사항 관리 화면으로 이동합니다.
  2. 현재 노출 중인 공지사항 목록을 확인합니다.
  3. 노출을 종료할 공지사항을 선택합니다.
  4. 노출 종료 기능을 실행합니다.
  5. 해당 공지사항이 이력 목록으로 이동했는지 확인합니다.

종료된 공지사항 다시 노출하기

  1. 공지사항 관리 화면에서 이력 목록을 확인합니다.
  2. 다시 노출할 공지사항을 찾습니다.
  3. 재노출 기능을 실행합니다.
  4. 해당 공지사항이 현재 노출 목록에 추가되었는지 확인합니다.
  5. 필요한 경우 공지사항의 노출 순서를 조정합니다.

참고

공지사항의 노출을 종료하더라도 기존 내용은 이력에 보관됩니다.

행사 운영 중 반복적으로 사용하는 안내문은 이력에서 다시 노출하여 활용할 수 있습니다.

주의사항

종료된 공지사항을 다시 노출할 때는 안내 내용이 현재 행사 운영 상황과 일치하는지 반드시 확인해 주세요.

특히 행사 날짜, 운영 시간, 통제 구역 등의 정보가 변경되었을 수 있으므로 재노출 전에 내용을 검토하는 것이 좋습니다.

5.6. 콘텐츠 등록 후 확인 ​

모든 콘텐츠를 등록한 뒤에는 실제 안내 페이지에 정상적으로 반영되었는지 확인해야 합니다.

① 상세 콘텐츠 확인 ​

  1. 방문객용 안내 페이지에 접속합니다.
  2. 등록한 상세 콘텐츠를 확인합니다.
  3. 제목, 설명, 이미지 등이 정상적으로 표시되는지 점검합니다.
  4. 연결된 버튼 및 링크의 동작을 확인합니다.

② 일정 확인 ​

  1. 방문객용 안내 페이지의 일정 화면으로 이동합니다.
  2. 등록한 일정의 날짜와 시간을 확인합니다.
  3. 카테고리 및 배지가 올바르게 적용되었는지 확인합니다.
  4. 관련 상세 콘텐츠로 정상적으로 이동하는지 확인합니다.

③ 공지사항 확인 ​

  1. 방문객용 안내 페이지에서 공지사항을 확인합니다.
  2. 등록한 문구가 정상적으로 표시되는지 확인합니다.
  3. 중요 공지의 노출 순서가 적절한지 점검합니다.

④ 최종 점검 항목 ​

  • 상세 콘텐츠의 제목과 설명이 정확한지 확인
  • 이미지와 영상이 정상적으로 표시되는지 확인
  • 주요 정보 및 상세 일정이 올바르게 등록되었는지 확인
  • 일정 시작일과 종료일이 정확한지 확인
  • 반복 일정이 의도한 날짜와 시간으로 구성되었는지 확인
  • 일정 카테고리와 배지가 정상적으로 표시되는지 확인
  • 관련 콘텐츠 연결이 정상적으로 동작하는지 확인
  • 공지사항의 내용과 노출 순서가 올바른지 확인
  • 모바일 환경에서 콘텐츠가 정상적으로 표시되는지 확인

참고

행사 운영 중 일정이나 프로그램 정보가 변경되었다면 CMS에서 수정한 후 실제 방문객용 안내 페이지에도 변경 사항이 반영되었는지 확인해 주세요.
