6. 투어맵 구성 및 관리 ​

투어맵은 축제 및 행사장의 주요 장소와 시설을 지도에 표시하여 방문객에게 위치 정보를 제공하는 기능입니다.

프로젝트 운영자는 CMS에서 지도 표시 범위를 설정하고, 이미지 오버레이, 선·다각형, 맞춤형 마커 등을 등록하여 행사 특성에 맞는 안내 지도를 구성할 수 있습니다.

또한 지도 객체를 선택했을 때 상세 콘텐츠나 간단한 안내 정보를 제공하도록 바텀시트를 설정할 수 있습니다.

6.1. 투어맵 기능 안내 ​

투어맵에서는 다음과 같은 기능을 제공합니다.

기능설명
지도 기본 설정초기 지도 위치, 확대 수준 및 표시 범위 설정
지리 참조 이미지행사장 배치도나 안내 이미지를 지도 위에 표시
선/다각형이동 경로와 행사 구역을 선 또는 도형으로 표시
맞춤형 마커주요 시설과 장소의 위치를 이미지 마커로 표시
지도 카테고리지도 객체를 유형별로 분류
바텀시트지도 객체 선택 시 관련 정보 제공
상세 콘텐츠 연결기존에 등록한 상세 콘텐츠와 지도 객체 연결

지도 요소활용 예시
지리 참조 이미지축제장 배치도, 부스 배치도

바텀시트장소 소개, 운영 시간, 관련 콘텐츠 안내

6.2. 지도 기본 설정 ​

지도 기본 설정에서는 방문객이 투어맵을 이용할 때 표시되는 초기 위치와 지도 확대 수준 등을 설정합니다.

행사장이 위치한 지역과 실제 운영 범위에 맞게 설정하는 것이 중요합니다.

① 지도 기본 설정 화면 이동 ​

  1. 프로젝트 관리 화면에서 투어맵 지도 설정 화면으로 이동합니다.
  2. 현재 설정된 지도 확대 수준과 중심 좌표를 확인합니다.
  3. 필요한 값을 변경한 후 저장합니다.

② 지도 확대 수준 설정 ​

줌 레벨(Zoom Level)은 지도를 얼마나 확대하거나 축소하여 표시할지를 결정하는 값입니다.

항목설명
초기 카메라 Zoom Level방문객이 지도를 처음 열었을 때의 확대 수준
최대 Zoom Level사용자가 확대할 수 있는 최대 수준
최소 Zoom Level사용자가 축소할 수 있는 최소 수준

설정 방법

  1. 초기 카메라 Zoom Level 값을 입력합니다.
  2. 최대·최소 Zoom Level을 설정합니다.
  3. 설정한 값이 적절한지 확인합니다.
  4. 저장 버튼을 클릭합니다.

참고

줌 레벨이 높을수록 지도가 확대되고, 낮을수록 더 넓은 지역이 표시됩니다.

초기 줌 레벨은 행사장의 주요 구역이 한눈에 들어오는 수준으로 설정하는 것을 권장합니다.

③ 지도 중심 좌표 설정 ​

지도 중심 좌표는 방문객이 투어맵을 처음 열었을 때 지도 중앙에 표시되는 위치입니다.

항목설명
초기 카메라 위도지도 중심의 남북 위치
초기 카메라 경도지도 중심의 동서 위치

설정 방법

  1. 지도에서 행사장의 중심 위치로 이동합니다.
  2. 초기 위치로 설정 기능을 이용하거나 위도와 경도를 직접 입력합니다.
  3. 설정된 위치를 확인합니다.
  4. 변경 내용을 저장합니다.

④ 지도 표시 범위 제한 ​

지도 표시 범위 제한은 방문객이 지도를 탐색할 수 있는 지역을 지정하는 기능입니다.

다음 좌표를 이용하여 범위를 설정합니다.

항목설명
서남쪽 위도표시 범위의 남쪽 경계
서남쪽 경도표시 범위의 서쪽 경계
동북쪽 위도표시 범위의 북쪽 경계
동북쪽 경도표시 범위의 동쪽 경계

설정 방법

  1. 지도 표시 범위 제한 영역으로 이동합니다.
  2. 행사장 전체를 포함하도록 서남쪽과 동북쪽 좌표를 입력합니다.
  3. 설정한 범위가 적절한지 확인합니다.
  4. 저장 버튼을 클릭합니다.

주의사항

표시 범위를 너무 좁게 설정하면 방문객이 행사장 일부 시설이나 주변 지역을 확인하지 못할 수 있습니다.

행사장 입구, 주차장 등 주요 시설을 포함하도록 여유 있는 범위를 설정하는 것을 권장합니다.

⑤ 지도 기본 설정 저장 및 기능 활성화 ​

투어맵의 다른 관리 기능을 사용하려면 지도 기본 설정을 먼저 저장해야 합니다.

지도 중심 좌표, 확대 수준 등의 기본 설정이 저장되지 않은 상태에서는 구역 오버레이 등 다른 지도 관리 기능을 이용할 수 없습니다.

설정 방법

  1. 투어맵 기본 설정 화면으로 이동합니다.
  2. 초기 카메라 Zoom Level을 설정합니다.
  3. 지도 중심 좌표를 설정합니다.
  4. 최소·최대 Zoom Level 및 지도 표시 범위를 설정합니다.
  5. 저장 버튼을 클릭합니다.
  6. 저장이 완료되면 다른 투어맵 관리 기능을 이용할 수 있습니다.

중요

지도 기본 설정 저장은 투어맵을 구성하기 위한 필수 선행 작업입니다.

지도 기본 설정을 저장하지 않으면 다른 지도 관리 기능이 비활성화되어 이용할 수 없습니다.

투어맵을 처음 구성하는 경우 반드시 기본 설정을 먼저 완료해 주세요.

⑥ 지도 기본 설정 완료 후 진행할 작업 ​

지도 기본 설정을 저장한 후에는 다음과 같은 작업을 진행할 수 있습니다.

  • 지리 참조 이미지 등록
  • 선 및 다각형 생성
  • 맞춤형 마커 등록
  • 지도 객체별 바텀시트 설정
  • 지도 카테고리 구성 및 관리

각 기능의 자세한 설정 방법은 다음 절부터 순서대로 안내합니다.

6.3. 투어맵 관리 화면 구성 ​

투어맵은 지도 기본 설정과 구역 오버레이 편집 화면을 통해 관리할 수 있습니다.

① 투어맵 관리 화면 이동 ​

  1. 프로젝트 관리 화면에 접속합니다.
  2. 좌측 메뉴에서 투어맵 관련 메뉴를 선택합니다.
  3. 지도 기본 설정 또는 구역 오버레이 관리 화면으로 이동합니다.

② 지도 편집 화면 구성 ​

구역 오버레이 관리 화면에서는 지도 객체를 추가하거나 위치 및 속성을 수정할 수 있습니다.

영역설명
레이어 선택편집할 지도 객체 유형 선택
객체 목록해당 레이어에 등록된 객체 확인
지도 편집 영역객체의 실제 위치 및 형태 편집
속성 편집 영역선택한 객체의 디자인과 연결 정보 설정
저장변경한 지도 설정 저장

③ 지도 레이어 종류 ​

지도 객체는 크게 3가지 레이어로 구분하여 관리합니다.

레이어설명
지리 참조 이미지이미지 파일을 지도 위에 배치
선/다각형선, 사각형, 자유 다각형, 원형 구역 표시
맞춤형 마커특정 장소의 위치를 이미지 마커로 표시

④ 레이어 표시 및 편집 잠금 ​

각 레이어에서는 표시 여부와 편집 잠금을 설정할 수 있습니다.

  • 표시/숨김: 편집 화면에서 해당 레이어를 보이거나 숨깁니다.
  • 편집 잠금: 실수로 객체를 이동하거나 수정하지 않도록 잠급니다.
  • 레이어 선택: 해당 유형의 지도 객체를 선택하고 편집합니다.

참고

표시/숨김 및 편집 잠금은 지도 편집 작업을 편리하게 수행하기 위한 기능입니다.

방문객용 화면의 노출 여부와는 구분하여 사용해 주세요.

6.4. 지리 참조 이미지 관리 ​

지리 참조 이미지는 행사장 배치도, 평면도 등의 이미지 파일을 지도 위에 배치하는 기능입니다.

행사장의 실제 구조를 이미지로 표현하여 방문객이 부스 배치나 행사 공간을 쉽게 이해할 수 있도록 구성할 수 있습니다.

① 지리 참조 이미지 등록 ​

  1. 투어맵 > 구역 오버레이 화면으로 이동합니다.
  2. 지리 참조 이미지 레이어를 선택합니다.
  3. 이미지 객체를 추가합니다.
  4. 지도에 표시할 이미지 파일을 등록합니다.
  5. 이미지의 위치와 크기를 조정합니다.
  6. 저장 버튼을 클릭합니다.

② 이미지 위치 및 크기 조정 ​

이미지는 지도 위에서 실제 행사장 위치에 맞게 배치할 수 있습니다.

설정 방법

  1. 이미지 객체 목록에서 수정할 이미지를 선택합니다.
  2. 지도 위에 표시된 이미지를 확인합니다.
  3. 이미지의 꼭짓점 또는 편집 도구를 이용하여 위치와 크기를 조정합니다.
  4. 실제 지도상의 행사장 위치와 일치하는지 확인합니다.
  5. 변경 내용을 저장합니다.

③ 이미지 표시 설정 ​

지리 참조 이미지에서는 다음 속성을 설정할 수 있습니다.

항목설명
이미지지도에 표시할 이미지 파일
위치이미지가 배치되는 지도 좌표
불투명도이미지의 투명도
줌 레벨 표시 제한지정한 확대 수준에서만 이미지 표시
최소·최대 줌 레벨이미지 표시 범위 지정
선택 스타일이미지 선택 시 적용할 CSS 스타일

불투명도

이미지의 불투명도를 조절하여 지도 배경이 함께 보이도록 설정할 수 있습니다.

줌 레벨 표시 제한

특정 확대 수준에서만 이미지가 표시되도록 설정할 수 있습니다.

선택 스타일

방문객이 해당 이미지를 선택했을 때 적용할 CSS 스타일을 입력할 수 있습니다.

예를 들어 그림자 효과를 적용하여 선택된 이미지를 시각적으로 강조할 수 있습니다.

주의사항

바텀시트를 표시하지 않도록 설정한 이미지 객체는 방문객 화면에서 선택되지 않으므로 선택 스타일도 적용되지 않습니다.

6.5. 선 및 다각형 관리 ​

선/다각형 기능은 지도 위에 이동 경로와 행사 구역 등을 표시하는 기능입니다.

행사장 이동 동선, 공연 구역, 체험 공간 또는 출입 통제 구역을 표시하는 데 사용할 수 있습니다.

① 선/다각형 추가 ​

  1. 투어맵 > 구역 오버레이 화면으로 이동합니다.
  2. 선/다각형 레이어를 선택합니다.
  3. 원하는 도형 도구를 선택합니다.
  4. 지도 위에 선 또는 도형을 생성합니다.
  5. 위치와 형태를 조정합니다.
  6. 설정을 저장합니다.

② 도형 유형 ​

도구설명활용 예시
Pen여러 지점을 연결하여 선 생성이동 경로, 동선 안내
Rect사각형 구역 생성부스 및 시설 구역
Free자유로운 형태의 다각형 생성불규칙한 행사 구역
Circle원형 구역 생성원형 광장, 특정 시설 주변

③ 도형 위치 및 형태 수정 ​

  1. 객체 목록에서 수정할 도형을 선택합니다.
  2. 지도 위에서 도형의 위치나 형태를 조정합니다.
  3. 실제 행사 구역과 일치하는지 확인합니다.
  4. 변경 내용을 저장합니다.

④ 도형 스타일 설정 ​

도형은 기본 상태와 선택 상태의 스타일을 설정할 수 있습니다.

항목설명
채우기 색도형 내부에 표시할 색상
채우기 불투명도도형 내부의 투명도
외곽선 색도형 테두리 색상
외곽선 스타일실선, 점선 등 선의 형태
외곽선 두께도형 테두리의 두께
라벨지도 위에 표시할 이름
라벨 색상라벨 텍스트 색상
선택 스타일객체 선택 시 적용할 시각적 효과

설정 방법

  1. 수정할 도형을 선택합니다.
  2. 속성 편집 화면에서 기본 스타일을 설정합니다.
  3. 필요한 경우 선택 스타일을 설정합니다.
  4. 변경 내용을 저장합니다.

⑤ 도형 라벨 설정 ​

라벨을 이용하면 지도 위에 행사 구역의 이름을 표시할 수 있습니다.

예를 들어 다음과 같은 문구를 등록할 수 있습니다.

  • 메인 공연장
  • 체험존
  • 푸드존
  • 전시 구역

라벨의 색상, 외곽선, 불투명도 등을 조정하여 지도 배경과 구분되도록 설정할 수 있습니다.

참고

여러 행사 구역을 표시할 때는 구역별 색상을 구분하면 방문객이 지도 정보를 더 쉽게 이해할 수 있습니다.

채우기 불투명도를 적절하게 조정하여 지도 배경이 가려지지 않도록 설정하는 것을 권장합니다.

6.6. 맞춤형 마커 관리 ​

맞춤형 마커는 지도에서 특정 장소나 시설의 위치를 이미지 아이콘으로 표시하는 기능입니다.

안내소, 화장실, 주차장, 공연장, 체험 부스 등 방문객에게 위치를 안내할 시설을 등록할 수 있습니다.

① 맞춤형 마커 등록 ​

  1. 투어맵 > 구역 오버레이 화면으로 이동합니다.
  2. 맞춤형 마커 레이어를 선택합니다.
  3. 새로운 마커를 추가합니다.
  4. 지도에서 마커가 표시될 위치를 지정합니다.
  5. 마커 이미지 및 속성을 설정합니다.
  6. 변경 내용을 저장합니다.

② 마커 위치 설정 ​

마커는 지도에서 위치를 지정하거나 좌표를 이용하여 배치할 수 있습니다.

항목설명
위도마커의 남북 방향 위치
경도마커의 동서 방향 위치

마커를 등록한 뒤에는 실제 시설의 위치와 일치하는지 확인해 주세요.

③ 기본 마커 설정 ​

기본 마커는 방문객이 해당 마커를 선택하지 않았을 때 표시되는 이미지입니다.

설정 방법

  1. 마커 속성 편집 화면으로 이동합니다.
  2. 기본 마커 영역에서 사용할 이미지를 등록합니다.
  3. 마커의 크기를 설정합니다.
  4. 필요에 따라 위치 오프셋을 설정합니다.
  5. 변경 내용을 저장합니다.
항목설명
마커 이미지지도에 표시할 기본 이미지
마커 크기이미지의 가로 및 세로 크기
오프셋실제 좌표를 기준으로 이미지가 표시되는 위치 조정

④ 선택 마커 설정 ​

선택 마커는 방문객이 마커를 선택했을 때 표시되는 이미지입니다.

기본 마커와 다른 이미지를 사용하여 현재 선택된 장소를 강조할 수 있습니다.

설정 방법

  1. 선택 마커 설정 영역으로 이동합니다.
  2. 사용할 선택 마커 이미지를 등록합니다.
  3. 선택 마커의 크기와 오프셋을 설정합니다.
  4. 변경 내용을 저장합니다.

⑤ 마커 선택 가능 여부 설정 ​

마커 선택 가능 여부를 설정하여 방문객이 해당 마커를 선택할 수 있는지 결정합니다.

  • 선택 가능: 방문객이 마커를 선택할 수 있음
  • 선택 불가: 방문객이 마커를 선택할 수 없음

위치 표시만을 목적으로 사용하는 마커는 필요에 따라 선택 기능을 비활성화할 수 있습니다.

⑥ 마커 줌 레벨 설정 ​

마커는 지정한 확대 수준에서만 표시되도록 설정할 수 있습니다.

항목설명
줌 레벨 표시 제한특정 확대 수준에서 마커 표시
최소 줌 레벨표시를 시작하는 최소 확대 수준
최대 줌 레벨표시가 허용되는 최대 확대 수준

마커가 많은 지도에서는 줌 레벨을 적절히 설정하면 화면이 복잡해지는 것을 줄일 수 있습니다.

⑦ 마커 라벨 설정 ​

마커에 표시할 이름을 설정할 수 있습니다.

예를 들어 '안내소', '화장실', '메인 무대' 등을 표시할 수 있습니다.

기본 상태와 선택 상태에서 라벨의 표시 방식을 구분하여 설정할 수 있습니다.

참고

마커 이미지의 크기가 지나치게 크거나 라벨이 많으면 지도 화면이 복잡해질 수 있습니다.

방문객이 사용하는 모바일 화면을 기준으로 크기와 표시 수준을 조정하는 것이 좋습니다.

6.7. 바텀시트 설정 ​

바텀시트는 방문객이 투어맵에서 지도 객체를 선택했을 때 화면 하단에 관련 정보를 표시하는 기능입니다.

장소 소개, 운영 시간, 시설 안내 등의 정보를 제공하거나 기존에 등록한 상세 콘텐츠를 연결하여 표시할 수 있습니다.

① 바텀시트 설정 ​

  1. 바텀시트를 설정할 지도 객체의 레이어를 선택합니다.
  2. 객체 목록에서 설정할 객체를 선택합니다.
  3. 속성 편집 영역의 클릭 시 이벤트 설정 항목으로 이동합니다.
  4. 사용할 바텀시트 유형을 선택합니다.
  5. 선택한 유형에 따라 정보를 입력하거나 상세 콘텐츠를 연결합니다.
  6. 저장 버튼을 클릭합니다.

② 바텀시트 유형 ​

지도 객체의 용도와 제공할 정보에 따라 바텀시트 유형을 설정할 수 있습니다.

유형설명활용 예시
바텀시트 표시 안함지도 객체를 선택했을 때 바텀시트를 표시하지 않음행사장 배치도, 이동 경로
단일 POI 바텀시트연결된 하나의 상세 콘텐츠 정보를 표시공연장, 체험 부스
POI 목록 바텀시트연결된 여러 상세 콘텐츠를 목록 형태로 표시푸드존, 체험존
단순정보 바텀시트직접 입력한 간단한 안내 정보를 표시화장실, 주차장, 안내소

참고

POI(Point of Interest)는 지도에서 방문객에게 안내할 주요 장소 또는 관심 지점을 의미합니다.

③ 단일 POI 바텀시트 설정 ​

단일 POI 바텀시트는 하나의 지도 객체에 하나의 상세 콘텐츠를 연결하여 정보를 제공하는 기능입니다.

설정 방법

  1. 상세 콘텐츠를 연결할 지도 객체를 선택합니다.
  2. 클릭 시 이벤트 설정에서 단일 POI 바텀시트를 선택합니다.
  3. 연결할 상세 콘텐츠를 선택합니다.
  4. 변경 내용을 저장합니다.

예를 들어 메인 공연장 마커에 공연장 상세 콘텐츠를 연결하면 방문객이 지도에서 해당 마커를 선택했을 때 공연장 정보를 확인할 수 있습니다.

④ POI 목록 바텀시트 설정 ​

POI 목록 바텀시트는 하나의 지도 객체에 여러 상세 콘텐츠를 연결하여 목록 형태로 제공하는 기능입니다.

여러 시설이나 프로그램이 하나의 행사 구역에 포함되어 있는 경우 활용할 수 있습니다.

설정 방법

  1. 상세 콘텐츠 목록을 연결할 지도 객체를 선택합니다.
  2. 클릭 시 이벤트 설정에서 POI 목록 바텀시트를 선택합니다.
  3. 목록에 표시할 상세 콘텐츠를 선택하여 연결합니다.
  4. 연결된 콘텐츠를 확인한 후 변경 내용을 저장합니다.

예를 들어 푸드존을 표시하는 다각형에 여러 음식 판매 부스의 상세 콘텐츠를 연결하면 방문객이 해당 구역을 선택했을 때 음식 판매 부스 목록을 확인할 수 있습니다.

주의사항

지도에 등록된 마커가 POI 목록 바텀시트에 자동으로 추가되지는 않습니다.

목록에 표시할 상세 콘텐츠를 직접 연결해야 합니다.

⑤ 단순정보 바텀시트 설정 ​

단순정보 바텀시트는 별도의 상세 콘텐츠를 연결하지 않고 지도 객체에 대한 간단한 안내 정보를 제공하는 기능입니다.

화장실, 주차장, 안내소 등 간단한 정보만 필요한 시설에 활용할 수 있습니다.

설정 방법

  1. 안내 정보를 등록할 지도 객체를 선택합니다.
  2. 클릭 시 이벤트 설정에서 단순정보 바텀시트를 선택합니다.
  3. 방문객에게 제공할 안내 정보를 입력합니다.
  4. 변경 내용을 저장합니다.

⑥ 바텀시트 설정 확인 ​

바텀시트 설정을 완료한 후 방문객용 안내 페이지의 투어맵에서 해당 지도 객체를 선택하여 설정한 정보가 정상적으로 표시되는지 확인합니다.

참고

단일 POI 및 POI 목록 바텀시트를 이용하려면 연결할 상세 콘텐츠가 등록되어 있어야 합니다.

상세 콘텐츠 등록에 관한 자세한 내용은 5. 행사 콘텐츠 등록 및 관리에서 안내합니다.

6.8. 투어맵 구성 최종 확인 ​

투어맵 설정을 완료한 후 방문객용 안내 페이지에서 지도 구성과 주요 기능이 정상적으로 동작하는지 확인합니다.

① 방문객용 투어맵 확인 ​

  1. 투어맵 설정 및 변경 내용을 저장합니다.
  2. 방문객용 안내 페이지에 접속합니다.
  3. 투어맵 메뉴를 선택합니다.
  4. 지도에 등록한 이미지, 도형 및 마커를 확인합니다.
  5. 지도 객체를 선택하여 바텀시트와 연결된 콘텐츠를 확인합니다.

② 지도 구성 확인 ​

확인 항목확인 내용
초기 지도 위치행사장의 주요 구역이 표시되는지 확인
지도 확대 수준초기 및 최소·최대 줌 레벨이 적절한지 확인
지도 표시 범위주요 시설과 행사 구역을 확인할 수 있는지 확인
자리 참조 이미지실제 행사장 위치와 이미지 배치가 일치하는지 확인
선 및 다각형이동 경로와 행사 구역이 올바르게 표시되는지 확인
맞춤형 마커주요 장소 및 시설의 위치가 정확한지 확인
라벨지도 객체의 이름이 읽기 쉽게 표시되는지 확인

③ 지도 객체 및 연결 기능 확인 ​

확인 항목확인 내용
객체 선택선택 가능한 지도 객체가 정상적으로 선택되는지 확인
선택 스타일객체 선택 시 설정한 스타일이 적용되는지 확인
바텀시트설정한 유형에 따라 안내 정보가 표시되는지 확인
상세 콘텐츠연결한 상세 콘텐츠 정보가 올바르게 표시되는지 확인
POI 목록연결한 콘텐츠가 목록에 정상적으로 표시되는지 확인

④ 투어맵 최종 체크리스트 ​

  • 프로젝트의 투어맵 모듈이 활성화되어 있는지 확인
  • 지도 기본 설정 및 변경 내용 저장 완료
  • 초기 지도 위치 및 확대 수준 확인
  • 지도 표시 범위 확인
  • 자리 참조 이미지 위치 및 크기 확인
  • 선 및 다각형의 위치와 스타일 확인
  • 맞춤형 마커 위치 및 이미지 확인
  • 지도 객체의 선택 가능 여부 확인
  • 바텀시트 유형 및 표시 정보 확인
  • 상세 콘텐츠 연결 상태 확인
  • 모바일 화면에서 지도 표시 및 조작 상태 확인

참고

투어맵은 방문객이 모바일 기기에서 주로 이용하는 기능이므로 실제 모바일 화면을 기준으로 지도 객체의 크기, 라벨의 가독성 및 바텀시트 표시 상태를 확인하는 것을 권장합니다.

설정 내용을 수정한 경우 변경 내용을 저장한 후 방문객용 화면에서 다시 확인해 주세요.
